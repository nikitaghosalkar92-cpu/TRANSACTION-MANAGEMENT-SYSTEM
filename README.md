# TRANSACTION-MANAGEMENT-SYSTEM
Designed to manage and track financial transactions in a structured SQL database.

Includes tables for users, accounts, transactions, and transaction types.

Implements primary keys, foreign keys, and constraints for data accuracy and integrity.

Supports essential CRUD operations to add, update, delete, and retrieve records.

Tracks account balances and maintains a clear history of all transactions.

Demonstrates normalized database design for efficient storage and performance.

Contains SQL queries for reporting, summaries, and data analysis.

Suitable for learning database modeling, relational design, and SQL operations.

Ideal as a beginner-friendly mini project for banking or finance-based systems.
